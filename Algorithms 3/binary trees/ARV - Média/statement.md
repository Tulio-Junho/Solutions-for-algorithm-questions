# ARV - Média

## Descrição

Faça um programa que insira vários números inteiros em uma árvore binária e, depois, calcule a média dos elementos armazenados na árvore.

A média deve ser calculada através de uma função, com o seguinte cabeçalho:

```cpp
float media(treenodeptr arvore)
```

## Entrada

A entrada consiste em uma linha contendo vários números inteiros, que deverão ser inseridos na árvore.

A leitura deve terminar quando for informado o número `-1`, que não deve ser inserido na árvore.

## Saída

O programa deve informar a média dos elementos da árvore, com **2 casas decimais**, no seguinte formato:

```text
Media: 7.33
```

## Exemplo

**Entrada**
```text
8 3 10 14 6 4 13 7 1 -1
```

**Saída**
```text
Media: 7.33
```
