# ARV - Maior e Menor Elemento

## Descrição

Faça um programa que verifique qual é o menor e o maior elemento de uma árvore binária.

Para encontrar esses elementos, crie as seguintes funções:

```cpp
int maior(treenodeptr arvore)

int menor(treenodeptr arvore)
```

## Entrada

A entrada consiste em uma sequência de números inteiros, que deverão ser inseridos na árvore.

A leitura deve terminar quando for informado o número `-1`, que não deve ser inserido na árvore.

## Saída

O programa deve apresentar o menor e o maior elemento da árvore, separados por `e`.

## Exemplo

**Entrada**
```text
10 7 15 2 8 12 20 3 -1
```

**Saída**
```text
2 e 20
```
