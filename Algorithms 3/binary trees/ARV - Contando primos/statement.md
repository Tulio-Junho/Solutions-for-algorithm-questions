# ARV - Contagem de Números Primos

## Descrição

Faça um programa que leia vários números inteiros e os insira em uma árvore binária.

Depois, implemente uma função que percorra a árvore e conte quantos dos elementos armazenados são números primos.

A função deve possuir o seguinte cabeçalho:

```cpp
int contaPrimos(treenodeptr arvore)
```

Por fim, o programa deve utilizar essa função para mostrar a quantidade de números primos inseridos na árvore.

## Entrada

A entrada consiste em uma única linha contendo vários números inteiros positivos, que deverão ser inseridos na árvore.

A leitura termina quando for informado o número `-1`, que não deverá ser inserido na árvore.

## Saída

O programa deve mostrar a quantidade de números primos presentes na árvore.

## Exemplo

**Entrada**
```text
10 7 15 2 8 12 20 3 -1
```

**Saída**
```text
3 numeros primos
```
